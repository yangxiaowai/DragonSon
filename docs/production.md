# 制作与验证说明

DragonSon 保存“龙哥”的成品、选用源素材和最终检查记录。角色由四张用户提供的照片提炼而来，先生成基础形象，再按用户要求收窄脸颊、拉长脸型，并调整眉眼和鼻口比例。

## 制作过程

角色和动作条使用图像生成工具制作。基础形象确定后，各动作都以该形象为参考单独生成；视线方向先建立上下左右四个锚点，再生成两个连续的八方向动作条。照片仅在制作时作为参考，未收录进本仓库。

图像经过洋红色背景去除、完整人物组件提取、共享尺度和基线注册后，组装为精确网格。最终统一处理边缘色溢，并保存透明 PNG。此后所有展示预览均由同一份最终图集裁取，确保预览与成品一致。

保留的源素材位于 `source/canonical-base.png` 和 `source/strips/`。它们可用于后续定向修改；重建精确最终图还需要相应的提取、注册、组装及边缘处理流程。

## 图集规格

最终文件为 `assets/spritesheet.png`：

- PNG / RGBA，1536 × 2288 像素。
- 8 列、11 行；每格 192 × 208 像素。
- 前九行分别有 6、8、8、4、5、8、6、6、6 帧。
- 最后两行各有 8 帧，组成十六方向视线。
- 共 73 个有效单元；其余 15 格全透明。

第 9 行方向依次为 `000、022.5、045、067.5、090、112.5、135、157.5`；第 10 行依次为 `180、202.5、225、247.5、270、292.5、315、337.5`。角度以画面上方为起点顺时针增加。身体与脚保持稳定，头部通过俯仰、转动及眼睛朝向表达视线。

## 验证证据

`validation/` 保留经整理的最终检查报告。最终成品路径已映射到仓库位置；其他制作过程路径已去除本机目录前缀，部分指向未收录的中间帧。数值、结果和观察结论保持不变。

| 文件 | 检查范围 |
| --- | --- |
| `atlas.json` | 图集尺寸、格式、透明性、有效格和空白格 |
| `quality.json` | 跳跃位移、落地偏差、视线注册和必要报告 |
| `frame-review.json` | 九组动作的组件提取与帧完整性 |
| `direction-semantics.json` | 十六方向的预期、观察与具体视觉依据 |
| `continuity.json` | 相邻视线帧的面积、位置与像素变化 |
| `blind-validation.json` | 三份独立盲审的多数结果与方向核对 |
| `independent-visual-review.json` | 最终图集的独立视觉复核 |

最终成品在制作环境中通过了 Pets 上传前验证，并完成创建和启用。该账户操作记录不用于其他账户；本仓库不保存个人宠物 ID 或临时上传会话。

`tools/verify_assets.py` 只检查仓库资产与校验清单的完整性，不替代动作视觉复核、Pets 服务端验证或兼容性测试。更改角色图集后，应重新执行相应的完整验证流程。

## 已知轻微差异

连续性计算对 `157.5° → 180°` 给出一次局部像素差异警告。原生显示尺寸的顺序复核显示，头部由略向右低头过渡到正面低头，躯干和双脚稳定，未见明显跳变；方向盲审通过。

跳跃首末头顶位置比待机约低 7 像素，属于原生单元高度约 3.4% 的轻微差异。最终检查中，跳跃最大离地 32 像素，落地基线偏差为 0 像素。该差异已记录，未判为阻断性视觉问题。
